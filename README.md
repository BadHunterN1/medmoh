# Project 2

## Overview
This is a web template project featuring a modern, responsive design. It includes sections for articles, gallery, features, testimonials, clan members, services, skills, events, pricing plans, videos, stats, and a footer. The project uses HTML, CSS, and JavaScript, with assets such as images and webfonts included.

## Structure
- `index.html`: Main HTML file containing the structure of the website.
- `css/`: Contains CSS files for styling, including normalization and main styles.
- `js/`: Contains JavaScript files for interactivity.
- `imgs/`: Image assets used throughout the site.
- `webfonts/`: Font files for icons and typography.
- `links/`: Additional resources and subpages.

## How to Use
1. Open `index.html` in your browser to view the website.
2. Edit the CSS files in `css/` to customize the design.
3. Add or modify JavaScript in `js/` for additional functionality.
4. Replace images in `imgs/` as needed for your content.

## Features
- Responsive layout
- Font Awesome icons
- Google Fonts integration
- Multiple content sections
- Ready-to-customize template
